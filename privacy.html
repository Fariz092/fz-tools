Kebijakan Privasi

Kami menghormati privasi Anda. Halaman ini menjelaskan bagaimana FZTools menangani (atau lebih tepatnya, tidak menangani) data Anda.

1. Pengumpulan Data Pribadi

FZTools tidak mengumpulkan data pribadi apa pun dari pengguna. Kami tidak meminta nama, alamat email, nomor telepon, atau informasi identitas lainnya. Anda dapat menggunakan seluruh fitur situs ini secara anonim.

2. Data File & Gambar

Semua file yang Anda proses melalui alat di FZTools (gambar, teks, dll) diproses sepenuhnya di browser Anda. Kami tidak memiliki akses, tidak menyimpan, dan tidak mengirimkan file tersebut ke mana pun.

3. Pelacakan (Tracking) & Cookie

Kami tidak menggunakan cookie untuk periklanan, pelacakan analitik pihak ketiga (seperti Google Analytics), atau pixel pelacak. Situs ini dirancang agar bebas dari pelacakan untuk kenyamanan dan keamanan Anda.

4. Tautan Pihak Ketiga

Situs ini mungkin berisi tautan ke situs eksternal (seperti GitHub). Kami tidak bertanggung jawab atas praktik privasi atau konten dari situs pihak ketiga tersebut.

5. Perubahan Kebijakan

Jika ada pembaruan pada kebijakan privasi ini, kami akan memperbaruinya di halaman ini. Namun, komitmen kami untuk tetap menjadi platform yang bebas pelacakan dan menjaga privasi data Anda tidak akan berubah.
